# Vendored frequency corpus

`en-50k.tsv` — top 50,000 English word frequencies, vendored verbatim as the
build input for `dict/common-en.bin` (regenerated by
`node tools/build-dict.mjs --out dict/common-en.bin tools/corpus/en-50k.tsv`,
executed in subtask P1.M1.T1.S2).

## Source

- URL: <https://raw.githubusercontent.com/hermitdave/FrequencyWords/master/content/2018/en/en_50k.txt>
  (repo: <https://github.com/hermitdave/FrequencyWords>, `content/2018/en/en_50k.txt`)
- Variant: **RAW** (non-lemmatized) 2018 list — NOT the `qaredux` lemmatized
  variant. Rationale: hapax completes surface forms as typed; a lemmatized
  corpus would miss inflected forms (e.g. "them", "going"), which would fall
  through to the rank-group-0 "rare" band and pop completion menus — the
  exact failure BUG-001 describes.
- Data origin: OpenSubtitles 2018 (via OPUS, <http://opus.nlpl.eu/OpenSubtitles2018.php>).
  Dialogue register — hence `you`/`i` outrank `the`; this is expected and
  passes the sanity gate (the/with/this all within the top 100).

## Retrieval

- Date: 2026-09-07
- Download command:

  ```bash
  curl -sL -o /tmp/en_50k.txt \
    https://raw.githubusercontent.com/hermitdave/FrequencyWords/master/content/2018/en/en_50k.txt
  ```

- Conversion (SPACE → TAB separation; `tools/build-dict.mjs` `mergeTsv()`
  requires TAB separators; line order = rank, counts verbatim, no filtering,
  no re-sorting):

  ```bash
  tr ' ' '\t' < /tmp/en_50k.txt > tools/corpus/en-50k.tsv
  ```

- Integrity (vendor-time): source `en_50k.txt` sha256
  `5351ff405b1126ef555791dd4d9798a48e3e9a501a9fc481a9da957752cfb458`;
  converted `en-50k.tsv` sha256
  `f036e508bf469467217ccdf6c7ae80cf1c9dd57f3c35134314cccffe69e91543`.

## Format

- 50,000 lines; each line `word<TAB>count`; line order = frequency rank
  (count-descending in the source).
- Head (ranks 1–10): `you i the to a 's it and that 't`.

## Build-time filtering note (do NOT pre-filter)

988 of the 50,000 words do not match `build-dict.mjs`'s
`KEY_RE = /^[a-z][a-z0-9_-]{1,31}$/` (e.g. `'t`, `'s`, punctuation-bearing
forms). These are **intentionally kept** in this TSV: `build-dict.mjs` filters
them at build time. Pre-filtering here would shift the ranks of all subsequent
entries relative to the source corpus; keeping them verbatim keeps ranks
aligned with the vendor source and with the P1.M1.T2 band calibration.
