## Semantics worked out (edge cases)
- f empty (`""`): anchor f[0] undefined → return null. Zero-fragment listing (`#` alone) is rankMatches' special case (T2), never matchFragment's.
- f length 1 ("z"): anchor holds + empty tail → trivially tier 3, score 100 (1-char fragments answer — provider auto-open contract).
- f.length > c.length → null (subsequence impossible). f === c → tier 3.
- Tier precedence: check tier 3 first (c starts with f), then tier 2 (c.indexOf(f.slice(1), 1) !== -1 — run start ≥ 1; charsSkippedBeforeRun = runStart − 1), else tier 1 iff the greedy anchored subsequence succeeds.
- Greedy leftmost two-pointer pass computes BOTH the tier-1 trace (gapRuns = number of gap stretches between consecutive matched f chars; gapChars = total skipped chars in c between matched positions, EXCLUDING skip before the first matched tail char? Decision: gapChars counts only gaps BETWEEN matched f[1..] chars — the anchor char is not gapped) and detects the tier-2 contiguity (a tier-1 trace with zero gaps = contiguous run).
- Score formulas (spec §04 h2.28 verbatim): tier 3 → 100; tier 2 → 85 − 40·(charsSkippedBeforeRun / len(c)); tier 1 → 50 − 5·gapRuns − min(gapChars, 15). Integer results: round/`Math.round` — the spec says "integer score 0–100"; clamp to [0, 100] defensively (formula can't exceed bounds mathematically, but rounding could produce e.g. 85.0).
- Worked examples (spec-quoted): zsk→zendesk: run "sk" at index 4, skip=3, len=7 → 85−40·3/7 ≈ 68 (spec's ≈62 in the PRD prose refers to the gating example; compute exact in tests via the formula, don't hardcode prose approximations). hrp→handleResponseProxy: scattered, tier 1. hr→handleResponse ≈69 per prose — tier 2 ('r' at index 1, skip 0) → 85 − 0 = 85?
